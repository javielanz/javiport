# javiport

Portfolio for Javier Lanz Bethencourt — Content Strategist, Caracas.

## Development

```bash
npm install
npm run dev       # http://localhost:4321/javiport/es/
npm run build
npm run preview
```

## Deploy

Push to `main` → GitHub Actions deploys to https://javielanz.github.io/javiport/

## Stack

Astro 5 · Tailwind CSS 4 · Motion One · React islands · GitHub Pages
