# javiport

Portfolio for Javier Lanz Bethencourt — Content Strategist, Caracas.

## Development

```bash
npm install
npm run dev       # http://localhost:4321/javiport/es/
npm run build
npm run preview
npm run lint && npm run check:parity && npm run check   # pre-push gates
```

## Deploy

Push to `main` → GitHub Actions deploys to https://javielanz.github.io/javiport/

## Stack

Astro 5 · Tailwind CSS 4 · three.js (hero prism) · vanilla Astro scripts · GitHub Pages
